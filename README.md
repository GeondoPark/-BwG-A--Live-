## 🟢 Prompt 1: 기본 스튜디오 생성 (5대 지표 & 멀티모달 영상 분석)

```text
유튜브 영상을 업로드하기 전에 AI가 실제 화면(시각), 목소리·BGM(오디오), 대사(텍스트)를 모두 직접 시청하고 5가지 핵심 지표와 실시간 팩트체크로 성적표를 매겨주는 웹앱 'AI 영상 평가단'을 만들어줘.

[기술 및 멀티모달 정확도 핵심 규칙 (절대 준수)]
1. 스택: React(Vite, TS, Tailwind CSS, lucide-react) + Express(server.ts, @google/genai, youtube-transcript)
2. 모델: 모든 단계에서 반드시 "gemini-3.8-flash"만 사용해.
3. [🚫 예시 영상·샘플 데이터·초기 더미 결과 절대 생성 금지 (필수)]:
   - 코드 안에 SAMPLE_VIDEOS, EXAMPLE_URLS, MOCK_DATA, INITIAL_RESULT 같은 예시 상수나 가짜 데이터를 절대 만들지 마!
   - URL 입력창 아래에 '예시 영상 1', '샘플 링크 넣기', '데모 결과 보기' 같은 예시 버튼을 절대 만들지 마!
   - 앱을 처음 열었을 때 URL 입력창은 반드시 빈 문자열(useState(""))이어야 하고, 분석 결과 상태도 반드시 null(useState(null))이어야 해. 사용자가 직접 유튜브 URL을 입력하고 [평가 시작] 버튼을 눌러 실제 백엔드 API 응답이 오기 전에는 어떠한 예시 성적표나 예시 타임스탬프도 화면에 표시하지 마(분석 전에는 깔끔한 안내 Empty State만 표시할 것).
4. 백엔드 /api/analyze-video 3단계 멀티모달 파이프라인 (텍스트만 읽는 요약기 절대 금지!):
   - STEP 1 (초 단위 타임스탬프 앵커 확보):
     youtube-transcript로 영상 처음부터 끝까지 전체 대사와 정확한 시작 초(MM:SS, seconds)를 추출해(절대 중간에 slice로 자르지 말 것). 이 데이터는 영상의 실제 길이와 대사 시점을 맞추는 타임스탬프 기준표(Time-Anchor)로 사용해.
   - STEP 2 (Agentic Video 멀티모달 시청 — 🖼️시각 + 🔊오디오 + 📝텍스트 통합 분석, 무조건 실행!):
     자막 유무와 상관없이 반드시 아래 정확한 형식으로 ai.interactions.create를 호출해 영상을 직접 시청해:
       const interaction = await ai.interactions.create({
         model: "gemini-3.8-flash",
         input: [
           {
             type: "video",
             uri: youtubeUrl,
             mime_type: "video/mp4",
             processing: "agentic"
           },
           {
             type: "text",
             text: "타임스탬프 기준표(STEP 1)를 시간 앵커로 삼아, 영상의 처음부터 끝까지 직접 보고 들으며 [🖼️ 화면 연출·출연자 표정·컷 전환 속도], [🔊 목소리 톤·텐션·오디오 공백·BGM], [📝 실제 대사·스토리]를 통합 분석해줘..."
           }
         ]
       });
     이를 통해 아래 크리에이터 실전 5대 지표를 평가하고, 각 지표마다 🖼️시각적 근거(화면/표정)와 🔊청각·대사 근거(오디오/멘트)를 모두 포함해줘:
     ① 🧲 초반 생존력 (도입부 화면 훅·표정·오프닝 멘트가 시청자의 뒤로가기를 막을 만큼 강렬한가?)
     ② 🎢 텐션 & 몰입 유지력 (컷 전환이 느려지거나 오디오 텐션이 떨어져 앞감기를 누르게 되는 루즈 구간은 어딘가?)
     ③ 💥 킬링파트 & 댓글 화력 (출연자 연기·명장면·토론 떡밥 중 다 보고 기억에 남는 하이라이트는 어딘가?)
     ④ 🎯 제목·기대감 충족도 (초반 주제 기대감을 본편 영상미와 결말이 끝까지 충족하는가?)
     ⑤ 🛡️ 팩트 & 논란 방어력 (영상 속 수치·주장이나 장면 중 댓글창에서 공격받을 요소는 없는가?)
   - STEP 3 (Google Search 실시간 팩트체크):
     ai.models.generateContent (model: "gemini-3.8-flash", config: { tools: [{ googleSearch: {} }] })로 영상 속 주요 사실·통계·주장을 최신 웹 정보와 대조해 신호등 판정([✅ 팩트 확인], [⚠️ 맥락 보충 필요], [🚨 사실 오류 주의])과 출처 링크를 생성해.
5. 타임스탬프 정렬 규칙:
   - 새로운 URL을 입력해 분석을 시작하면 이전 결과 상태를 즉시 초기화해.
   - 모든 타임스탬프("MM:SS")와 seconds(분*60+초)는 실제 분석된 영상 시점과 100% 일치해야 해.

[UI 디자인: 한눈에 확 들어오는 모던 벤토 그리드(Bento Grid) 스튜디오 (다크 테마 bg-[#090D16])]
- [🚨 텍스트 잘림(...) 절대 금지 규칙 (필수 준수)]:
  모든 평가 지표 카드의 설명, 칭찬 장면(🟢), 아쉬운 장면(🟡), 팩트체크 코멘트에 Tailwind의 truncate, line-clamp-*, text-ellipsis, whitespace-nowrap, 또는 텍스트를 가리는 고정 높이(h-*, max-h-*)를 절대 사용하지 마!
  모든 카드와 장면 박스에는 반드시 whitespace-normal break-words h-auto를 적용해서 문장 전체가 ... 없이 끝까지 100% 다 읽히도록 렌더링해.
1. 상단 헤더 & URL 바:
   - 좌측에 '🎬 AI 영상 평가단' 로고, 중앙에 비어 있는 YouTube URL 입력창과 그라데이션 '[⚡ AI 멀티모달 영상 평가 시작]' 버튼만 깔끔하게 배치해(하단에 예시 URL 칩이나 샘플 버튼 절대 넣지 말 것).
2. 좌측(5컬럼) — 인터랙티브 영상 스테이지 (분석 완료 시 표시):
   - YouTube Iframe 플레이어: 우측 카드의 어떤 [▶ MM:SS] 타임스탬프 영역이든 누르면 즉시 해당 초(seekTo)로 점프해 자동 재생!
   - 타임라인 핫스팟 버튼 바: 플레이어 바로 아래에 실제 영상에서 찾아낸 핵심 순간들을 [🟢 MM:SS 칭찬/훅], [🟡 MM:SS 루즈 주의], [🔴 MM:SS 팩트 점검] 형태의 클릭형 칩 버튼(flex-wrap)으로 나열해 클릭 시 바로 이동하게 해줘.
   - 하단에 전 구간 멀티모달 타임라인 뷰어(📝 대사 + 🖼️ 화면/표정 + 🔊 오디오/텐션 요약 포함, 줄바꿈 전체 표시, 클릭 이동 지원) 배치.
3. 우측(7컬럼) — 한눈에 보는 비주얼 성적표 (분석 완료 시 표시):

   - 하단 '🌐 Google 실시간 팩트체크 신호등': 영상 속 주장 옆에 [✅ 팩트 확인], [⚠️ 맥락 보충 필요], [🚨 사실 오류 주의] 신호등 배지와 검증 설명 전문(whitespace-normal), 출처 링크를 깔끔하게 표시해줘.
```

## 🔵 Prompt 2: 내 채널 시청자 평가단 & 댓글 대첩 라운드 테이블 추가

```text
상단에 큼직한 모드 스위치 탭 2개를 만들어서 기존의 '[📊 1. 기본 5대 지표 평가]' 옆에 '[👥 2. 내 채널 맞춤형 가상 시청자 평가]' 모드를 추가해줘! (특정 채널명 예시 버튼이나 가짜 초기 더미 데이터를 절대 만들지 말고, 항상 빈 입력창에서 시작해 실제 실행 시에만 결과를 렌더링해!)

1. '유튜브 채널 링크(URL) 기반 가상 시청자 & 내 채널 맞춤형 5대 평가 지표 자동 생성':
   - '[👥 2. 내 채널 맞춤형 가상 시청자 평가]' 탭을 누르면, 상단에 비어 있는 유튜브 채널 링크 입력창(placeholder="내 유튜브 채널 링크(URL)를 입력하세요")과 '[🔍 내 채널 가상 시청자 & 맞춤 평가 지표 생성]' 버튼만 깔끔하게 배치해줘(예시 채널 버튼 절대 넣지 말 것).
   - 사용자가 유튜브 채널 링크를 입력하고 버튼을 누르면, 백엔드에서 "gemini-3.8-flash"와 googleSearch를 사용해 해당 채널의 콘텐츠 성격과 실제 댓글창의 시청자 반응 성향을 심층 분석해줘.
   - 분석 결과를 바탕으로 모든 채널에 똑같이 적용되는 획일적인 지표 대신, 이 채널의 시청자 성향에 따라 달라지는 '내 채널 맞춤형 5대 평가 지표'와 이를 각각 대표하는 '가상 시청자 5명'을 생성해 화면에 카드로 보여줘:
     * 각 가상 시청자 카드마다 ① 가상 시청자 이름 및 성향 요약(전체 시청자 중 차지하는 예상 비중 % 포함) ② 이 가상 시청자가 전담해서 채점할 '내 채널 맞춤형 평가 지표명'(예: 채널 특성에 맞춘 고유 지표명)과 세부 채점 기준 표시하고, 사용자가 원하면 텍스트나 평가 기준을 직접 수정할 수도 있게 해줘.
     
2. '기본 평가(1번)와 동일한 벤토 성적표 구조 + 내 채널 가상 시청자 맞춤형 채점 실행':
   - '[🎬 이 가상 시청자 기준으로 내 영상 평가하기]' 버튼을 누르면, ai.interactions.create (model: "gemini-3.8-flash", input: [{ type: "video", uri: youtubeUrl, mime_type: "video/mp4", processing: "agentic" }, ...])를 호출해 5명의 가상 시청자가 각자의 '내 채널 맞춤형 평가 지표' 기준으로 실제 영상의 화면·표정·오디오 호흡·대사를 직접 보고 들으며 채점하게 해줘. (동일한 영상 URL이면 STEP 1 타임스탬프 앵커는 기존 캐시를 즉시 재사용해!)
   - 평가 결과 화면은 1번 기본 모드와 통일감 있게 한눈에 비교되도록 아래 구조로 보여주되, 모든 텍스트는 말줄임표(...) 없이 끝까지 100% 다 읽히도록(w-full whitespace-normal break-words h-auto, truncate 및 line-clamp 절대 금지) 렌더링해줘:
     ① 상단 Hero 내 채널 맞춤 성적표 배너: 가상 시청자 5인의 가중치 합산 종합 점수(0~100점) 및 등급(S/A/B/C), 업로드 추천 여부 배지, 그리고 '내 채널 맞춤형 5대 평가 지표' 요약 프로그레스 바를 보여줘.
     ② 중단 '내 채널 맞춤형 5대 지표 & 가상 시청자' 벤토 카드 그리드 (1번 성적표와 동일한 레이아웃에 내 채널 맞춤 지표 적용):
        - 5개 카드마다 [내 채널 맞춤형 평가 지표명 + 담당 가상 시청자 프로필(비중 %)]과 점수, 그 가상 시청자의 실제 댓글 말투가 살아있는 한줄평, 그리고 '🖼️ 화면/연출 분석' · '🔊 오디오/대사 분석' 상세 코멘트를 보여줘.
        - 각 카드 하단에는 1번과 동일하게 가로 전체 폭(w-full whitespace-normal break-words) 박스로 클릭 시 영상 해당 초(MM:SS)로 즉시 점프하는 '[🟢 ▶ MM:SS 이 가상 시청자가 칭찬한 장면]'과 '[🟡 ▶ MM:SS 이 가상 시청자가 아쉬워한 장면]'을 문장 잘림(...) 없이 끝까지 보여줘.
     ③ 하단 '💬 가상 시청자 5인의 실시간 댓글 토론 & 우선순위 수정 체크리스트':
        - 5명의 가상 시청자가 실제 영상 타임스탬프([▶ MM:SS]) 장면을 지목하며 서로의 평가 기준에서 반박·옹호·절충하는 5~6턴의 생생한 댓글창 토론 뷰와, 업로드 전 가장 먼저 손봐야 할 타임스탬프 수정 체크리스트(체크박스 포함)를 보여줘.
```
